# 殆知阁导读

基于 [殆知阁古代文献简体库](https://github.com/robertsong2000/daizhigev20)（15,694 个文本、约 17.4 亿字）的十篇导读，每篇一个独立 HTML，无外部依赖，浏览器直接打开。

## 阅读

解压或克隆后，双击 **`mulu.html`**（总目），点击条目跳转各篇。四卷分编，卷色区分：

| 卷 | 主题 | 色印 | 篇目 |
|---|---|---|---|
| 卷一 | 总览 · 看结构 | 朱砂 | 十藏总目 · 朝代分布 |
| 卷二 | 名书 · 读经典 | 竹青 | 册府元龟 · 睡虎地秦简 · 洗冤集录 |
| 卷三 | 金源 · 访异朝 | 石青 | 中州集 · 中州集诗抄（书叶版） · 汝南遗事 |
| 卷四 | 鼎革 · 观易代 | 赭金 | 遗民书架 · 晚清州县官的一天 |

## 数据说明

- 全部古籍引文均经与库内文本逐字核验
- 朝代分布、字数、缺字率等数据为全库实测（详见 `dynasty-chart.html` 页脚口径说明）
- 《晚清州县官的一天》依据邱捷《晚清官场镜像》及澎湃新闻访谈；杜凤治日记原书不在本库
