岂有其人乎
神仙传晋 葛洪 十卷
问

弟子滕升发难：「先生曰神仙可得不死，可学古之神仙者，岂有其人乎？」这是全书的第一个问题，也是唯一的问题：神仙这种东西，真的有人做成过吗？

答

葛洪不辩论。他在《抱朴子内篇》里已经讲完了道理，这一回他换一种答辩方式：点名证人。「余今复抄集古之仙者，见于仙经服食方及百家之书，先师所说，耆儒所论，以为十卷，以传知真识远之士。」十卷卷宗，八十四份记录，从黄帝时代的广成子到三国吴的董奉，跨了将近三千年。 「与日月齐光，与天地为常，人其尽死，而我独存焉。」卷一开篇，广成子对黄帝说的话，也是全书的总纲。

本篇读法：不看神仙，只看证人。每一份记录里，葛洪几乎都留下了目击者。

序言里交代的底账：秦大夫阮仓记了数百人，刘向《列仙传》收七十一人，葛洪嫌刘向「殊甚简要，美事不举」，于是自己动手，把师传口说的、百家书里的证词重新归档。本页八席，是从八十四份记录里挑出的证词最扎实、汉语里最眼熟的八案。

贰 · 证人席

八份证词，八条证人链

每张卡读三样：竹签是卷次与人名，证词是库内原文，证人链是葛洪埋在故事里的目击者路线。神仙的事无法复验，他索性把目击者是谁、话是怎么传出来的写成一条链子，交由读者掂量。

卷二魏伯阳以死为饵

「伯阳乃服丹，丹入口即死。」丹成先喂白犬，犬死；三弟子相顾，师父自己吃，也死。谜底要等故事结尾才翻开：那是转数未足的毒丹，一场对信心的现场开卷考试。

证人链

服丹而死的虞姓弟子 → 出山买棺的二弟子 → 入山伐木的路人 → 乡里收到的那封谢罪信

卷二皇初平叱石成羊

「乃叱曰：『羊起！』于是白石皆变为羊，数万头。」牧羊少年失踪四十年，哥哥寻到金华山，只见满山东白石。一句「羊在耳，但兄自不见之」，提醒世人看见与否取决于道行。

证人链

市中善卜的道士 → 兄长初起亲眼往视 → 白石数万头

卷三王远 · 麻姑沧海桑田

「接待以来，已见东海三为桑田，向到蓬莱，水又浅于往昔。」方平笑曰：「圣人皆言，海中行复扬尘也。」神仙的闲谈里藏了汉语里最大的时间单位。这场家宴的排场也极写实：金鼓箫管人马之声先到，人后到。

证人链

平民蔡经举家 → 邻里皆闻鼓乐惊问 → 麻姑席间自述

卷五栾巴噀酒救火

「巴乃含酒起望西南噀之，奏云：『臣本乡成都市失火，故为救之。』」驿使回来报告：「正旦失火时，有雨自东北来，灭火，雨皆作酒气也。」一场跨千年的远程灭火，收据是成都会同的官方回报：那场雨，是酒味的。

证人链

正旦朝会满殿群臣 → 帝驰驿往问 → 成都市的火灾档案

卷六淮南王安鸡犬升天

「乃取鼎煮药，使王服之，骨肉近三百余人，同日升天，鸡犬舔药器者，亦同飞去。」最妙的是链尾：宗正按验谋反案，只捡到山石上的马蹄印，奏报朝廷。一份谋反案卷，办成了升天报告。武帝大懊恨，转身自己去求不死药，竟不得。

证人链

小臣伍被告变 → 宗正持节案淮南 → 奏帝，帝大懊恨

卷九壶公悬壶 · 葛陂龙

「常悬一空壶于坐上，日入之后，公辄转足跳入壶中，人莫知所在。」市掾费长房楼上独见，从此有了悬壶的名目。他的归途同样收得漂亮：「长房以所骑竹杖投葛陂中，视之，乃青龙耳。」卖药口不二价，得钱日收数万，转手施与市中贫冻者：一位把神仙做成了慈善的卖药人。

证人链

市中众人莫识 → 长房楼上日日供馔 → 家人发棺，棺中惟一竹杖

卷十董奉杏林

「又君异居山间，为人治病，不取钱物，使人重病愈者，使栽杏五株，轻者一株，如此数年，计得十万余株，郁然成林。」此后买杏不须报，自取，以谷一器换杏一器。多拿的，山里有虎追到家里如数吐出。此后「买杏者皆于林中自平量之，不敢有欺者」，虎成了制度本身。今天医生行当称「杏林」，是从这份证词里长出来的。

证人链

病愈者栽杏为据 → 取杏者自平量 → 偷杏者被虎逐，家人叩头送还

卷十李意期裂纸断军

「意期画作兵马器仗十数纸，便一一以手裂坏之，曰：『咄咄！』又画一大人，掘地埋之。」被问的是刘备：伐吴可行否。神仙不说话，只当众演示了一遍夷陵之战，随后归窟。蜀人后来干脆以他的脸色占卜日常吉凶，欢悦则百事吉。

证人链

「蜀郡人也，传世识之」的世代目击 → 玄德亲问 → 永安宫一病，果然是那张埋掉的画

叁 · 反方证人

八十四份里，只有他拒签

卷一的白石生，两千余岁，养猪牧羊攒钱买药，煮白石当饭，什么都好，唯独拒绝升天。彭祖问他为什么，他给出全书最不像神仙的一句话：

不升
卷一 · 白石生对彭祖问
「天上无复能乐于此间耶，但莫能使老死耳。天上多有至尊相奉事，更苦人间耳。」

天上也要排队拜见上级，比人间还累。时人于是称他「隐遁仙人」。葛洪把这句反方证词原样归档，放在全书第三篇，不动一字。这份诚实，是整部书最经得起读的地方。

肆 · 印谱

这套卷宗留给汉语的词

书里的证词大多没能说服后人相信神仙，却整整齐齐地住进了语言。八个案卷，出了五枚通用印：

叱石成羊皇初平 · 卷二
沧海桑田麻姑 · 卷三
鸡犬升天淮南王 · 卷六
悬壶壶公 · 卷九
杏林董奉 · 卷十

葛洪在序里说，这十卷是写给「知真识远之士」的，至于「系俗之徒」，不强求。一千六百多年过去，读者大概两样都占了：神仙没有收到太多信徒，这些词倒是一个字都没浪费。
